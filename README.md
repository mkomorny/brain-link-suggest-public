# Brain Link Suggest

> **Tri-Platform Agent Skill** for Claude Desktop / Code, Grok CLI, and Google Antigravity / Gemini.  
> Cross-Project Memory Synergy Discovery and Graph Linking — Surfaces unlinked memories across projects that share concepts, libraries, protocols, or architectural solutions, proposing explicit graph links.

---

## Overview

`brain-link-suggest` provides standardized capabilities across conversational AI platforms:
- Cross-project semantic affinity scanning.
- Shared technology, protocol, and concept cluster detection.
- Proposed /brain link commands with relationship types (extends, implements, depends_on).
- Tri-platform NTFS junctions connecting Claude, Grok, and Antigravity.
- Standard documentation suite: SKILL.md, HOW_TO_USE.txt, IMPLEMENTATION_PLAN.md, and README.md.

## Tri-Platform Architecture

Zero duplicate code across platforms. Canonical source resides in `.agents`:
- **Canonical Source**: `C:\Users\<you>\.agents\skills\brain-link-suggest`
- **Claude**: `C:\Users\<you>\.claude\skills\brain-link-suggest` (NTFS Junction)
- **Grok**: `C:\Users\<you>\.grok\skills\brain-link-suggest` (NTFS Junction)
- **Antigravity**: `C:\Users\<you>\.gemini\config\skills\brain-link-suggest` (NTFS Junction)
